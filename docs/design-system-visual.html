Use action red for small button labels with off-white text. Pure brand red is an expressive accent; it does not meet 4.5:1 with either brand text color. Charcoal on off-white is approximately 14.66:1; off-white on action red is 4.98:1.

Use in another project

Copy the shared foundations first, then add selected component implementations. The developer guide contains exact source paths, setup examples, behavior notes, and a starter prompt.

  1. Copy src/styles/tokens.css and foundations.css.
  2. Copy fonts.ts and the Danidin Bold, Leon Regular, and Leon Heavy WOFF2 files under the applicable license.
  3. Reuse src/components/ui/button.tsx. For liquid actions, copy both liquid-link.tsx and its CSS module.
  4. For themes, reuse theme.css, bootstrap, provider, and toggle; give the new product its own storage key.
  5. Apply your product’s own content, routes, media, and submission behavior.
@import "tailwindcss";
@import "../styles/tokens.css";
@import "../styles/foundations.css";
@import "../styles/theme.css"; /* optional */

The source files use Tailwind 4 directives. Other frameworks need plain-CSS translation of @theme, @utility, and @apply. This reference embeds that translation, plus the actual fonts and component styles.

Moriz identity assets, homepage trial sizes, the Diagnostic app, CMS, grain, Party Mode, and opening animation are separate choices. Success/warning palettes, loading states, and data-heavy components need new design decisions.
