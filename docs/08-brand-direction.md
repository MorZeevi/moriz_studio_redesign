## Typography

The selected direction is bold, editorial, expressive, creative, slightly brutalist and contemporary. Display/H1/H2 use the owner-supplied **Danidin CondensedBold** WOFF2 (actual family: Danidin Condensed Bold). Although the initial request named a Black face, the owner clarified the available WOFF2 by supplying CondensedBold; the implementation uses that real file rather than inventing a Black face. Body/UI/H3/H4 use **Leon Regular (400)** and **Leon Heavy (900)**. Both families cover Hebrew and Latin glyphs. No conversion was needed and the existing Danidin loader is reused.

Earlier candidates remain available in [the local font comparison](http://127.0.0.1:3000/he/fonts), but are not the shared foundation: Futurism Black, Manhattan 650 and Polin Regular/Bold. Their preloading is disabled; only the three selected font files preload on the homepage. See [the centralized scale and font-loading notes](09-design-system.md#typography).

## Color palette

Selected primitive palette: Primary **#FB2C36**, Secondary **#DDDC8C**, Dark **#262626**, Light **#FBFBFF**. Default primary text uses solid Dark with no opacity. Semantic surfaces, borders, focus and action states derive from those primitives. Primary buttons use a darker derived red for body-size text contrast. See [semantic usage](09-design-system.md#colors).
